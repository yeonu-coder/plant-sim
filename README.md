# 🌱 마이플랜테리어

게임처럼 가상의 새싹을 키우면서 생활 패턴과 집 환경을 알려 주면, 나에게 맞는 실내 식물 3가지를 추천해 주는 웹사이트예요.
추천받은 식물을 (가상으로) 구매해서 도감에 모을 수 있어요.

- **배포 주소:** https://yeonu-coder.github.io/plant-sim/
- 대학교 전공 수업 중간 프로젝트 (마감 2026년 11월 1일)

## 화면 흐름

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | 시작 | 서비스 소개, 경험 수준 고르기 (입문자 / 초보자 / 중급자 / 고수) |
| 2 | 새싹 키우기 게임 | 질문 7개(물 챙기기, 햇빛, 온도, 습도, 외출, 반려동물, 공간)에 답할 때마다 새싹이 5단계로 자라요 |
| 3 | 추천 결과 | 다 자란 캐릭터와 추천 식물 카드 3장. 카드마다 추천 이유가 한 줄씩 있어요 |
| 4 | 상세보기 | 다 자란 크기, 물 주기(쉬운 말 + 농사로 원문), 빛·온도·습도, 난이도, 반려동물, 수명, 꽃말, 항목별 출처 |
| 5 | 구매 → 주문 완료 | 가상의 동네 꽃집 3곳 중 하나를 골라 주문해요. **실제 결제가 아닌 시연용**이에요 |
| 6 | 도감 | 주문한 식물이 등록돼요. 아직 못 모은 식물은 실루엣으로 보이고, 5종·10종을 모으면 배지를 받아요 |

## 사용 기술

- **HTML, CSS, JavaScript**: 프레임워크나 빌드 도구 없이 만들었어요.
  - 한 페이지(`index.html`) 안의 화면들을 JavaScript로 보여 주고 숨겨요.
  - 데이터는 `.js` 파일에 넣었어요. 그래서 `index.html`을 더블클릭해서 열어도 동작해요.
  - 도감과 배지는 브라우저 **localStorage**에 저장해요. 회원가입이나 서버는 없어요.
  - 모바일(폭 360px)에 맞춰 먼저 만들었어요.
- **Python**: `scripts/convert_nongsaro.py`가 농사로 CSV를 점검하고, 식물 조건값으로 바꿔 줘요(`python3`만 있으면 돼요).

```
index.html            모든 화면이 들어 있는 페이지
css/style.css         색상 변수, 화면별 스타일
js/data/              식물 20종, 질문 7개, 꽃집 3곳 데이터
js/storage.js         도감·배지 저장 (localStorage)
js/recommend.js       추천 점수 계산
js/plant-image.js     식물 그림 (이미지가 없으면 이모지)
js/app.js             화면 전환과 각 화면 동작
assets/sprout/        새싹 성장 단계 그림 (SVG 5장)
scripts/              농사로 CSV 변환 스크립트
docs/                 데이터 규칙, 손 검산 기록
```

## 데이터 출처

- **농촌진흥청 농사로 「실내정원용 식물」 Open API 데이터** (2024.07.16 수집)
  - 2024년 해커톤에 참여했을 때 확보한 데이터를 이번 프로젝트에 맞게 다시 가공했어요.
  - 출처: 농사로 누리집 https://www.nongsaro.go.kr (Open API 「실내정원용 식물」)
- 식물 20종 중 **15종**은 이 데이터에서 빛, 물 주기, 온도, 습도, 난이도, 크기 값을 가져왔어요.
- 원본 CSV(`data/plants_nongsaro.csv`)는 **이 저장소에 올리지 않았어요.** 다시 배포해도 되는지 조건을 확인하지 못했기 때문이에요.

### 변환 스크립트 실행 방법

1. 농사로에서 「실내정원용 식물」 데이터를 받아 `data/plants_nongsaro.csv`로 저장해요(인코딩 cp949).
2. `plant-sim` 폴더에서 실행해요.

```bash
python3 scripts/convert_nongsaro.py --check   # 데이터 점검만 해요 (파일을 고치지 않아요)
python3 scripts/convert_nongsaro.py           # 점검 후 js/data/plants.js의 조건값을 바꿔요
```

- CSV가 없으면 받는 곳을 안내하고 끝나요.
- 같은 CSV로 몇 번을 다시 돌려도 결과가 같아요.
- 원본 CSV는 읽기만 하고 고치지 않아요.

## AI 초안 데이터와 공공데이터 구분

식물마다 `source`(출처) 값이 있고, 상세보기에서 **항목별로** 출처를 나눠서 보여 줘요.

| 구분 | 식물 | 어디서 온 값인지 |
|---|---|---|
| `"농사로 공공데이터"` | 몬스테라, 산세베리아 등 15종 | 빛·물 주기·온도·습도·난이도·크기는 스크립트가 CSV에서 만들어요. 손으로 고치지 않아요 |
| `"AI 초안"` | 로즈마리, 알로에 베라, 에케베리아, 하월시아, 올리브나무 | CSV에 없거나 값이 비어 있는 식물이에요. 화면에 **"AI 초안 정보"** 표시가 붙어요 |

- 농사로 식물이라도 **수명, 반려동물 안전 여부, 꽃말**은 CSV에 없어서 AI 초안이에요. 상세보기에 따로 표시돼요.
- CSV 값이 비어서 AI 초안으로 남은 항목은 `draftFields`에, 다른 이름·품종의 값을 쓴 경우는 `sourceNote`에 적었어요.
  - 예: 고무나무 → "데코라고무나무 값 사용"
- 확실하지 않은 정보는 지어내지 않고 `null`로 두었어요. 화면에는 **"확인 중"**으로 보여요(꽃말은 3종만 채움).
- 자세한 규칙:
  - [docs/data-rules.md](docs/data-rules.md): CSV 문장 → 조건값 변환표, 추천 점수 공식, 규칙을 바꾼 기록
  - [docs/hand-check.md](docs/hand-check.md): 추천 점수 손 검산 기록

## 수업 내용 적용

### 6주차: 스크립트로 계산하기, 데이터 점검, 손 검산

- **스크립트로 계산:** CSV 문장("토양 표면이 말랐을때" 등)을 숫자 조건값으로 바꾸는 일을 손으로 하지 않고 스크립트로 해요. 그래서 규칙을 바꾸면 다시 돌리기만 하면 돼요.
- **데이터 점검:** 스크립트가 변환하기 전에 CSV의 문제를 먼저 알려 줘요.
  - 값이 빈 줄 10개 (로즈마리, 인도고무나무 등)
  - 이름이 겹치는 식물 (렉스베고니아, 크로톤)
  - 엑셀 오류 값 `#ME?` (9칸)
  - 서로 바뀌어 들어간 열
  - CSV 독성 정보와 우리 `petSafe` 값 비교
- **손 검산:** 한 상황(그늘·건조·거의 못 챙김·잦은 외출·책상, 입문자)의 1~3위 점수를 손으로 계산했어요. 코드 결과(85 / 78 / 70)와 같은지 확인했어요 → [docs/hand-check.md](docs/hand-check.md)

### 5주차: 입력값 검사, 오류가 나도 멈추지 않기

- localStorage에서 읽은 값을 그대로 믿지 않고 먼저 검사해요(`js/storage.js`).
  - 값이 없거나 깨져 있으면(`{깨짐`, 숫자 등) → 빈 도감으로 시작
  - 없는 식물 id, 중복 → 버리고 우리 20종 id만 남김
  - 도감 개수와 맞지 않는 배지 기록 → 보여 주지 않음
- 저장이 막힌 브라우저(시크릿 창 등)에서도 화면은 멈추지 않고, "새로고침하면 사라질 수 있어요"라고 안내해요.
- 변환 스크립트도 CSV 파일이 없으면 오류로 멈추지 않고 안내 문구를 보여 줘요.

## AI 도구 사용

이 프로젝트는 **Claude Code**(AI 코딩 도구)를 사용해서 개발했어요.

- **내가 한 것:**
  - 기획: 서비스 아이디어, 화면 흐름, 질문 구성, 단계별 작업 순서
  - 데이터 판단: 농사로 데이터 사용, 식물 선정과 교체, 변환 규칙 결정(물 주기 기준, 온도 여유 3℃ 등), 한계를 그대로 둘지 결정
  - 검증: 단계마다 브라우저에서 직접 확인, 추천 점수 손 검산, 비교 상황을 정해 결과 검토
- **Claude Code가 한 것:**
  - 내 지시에 따라 코드, 변환 스크립트, 문서 초안을 작성
  - 자동 브라우저 테스트 실행
- 식물 정보 중 출처가 **"AI 초안"**인 값은 AI가 만든 초안이에요. 실제와 다를 수 있어서 화면에 표시해 두었어요.

## 실행 방법

- **인터넷으로:** 위 배포 주소로 접속해요.
- **내 컴퓨터에서:** 저장소를 내려받은 뒤 `index.html`을 더블클릭해요. 설치할 것은 없어요.
