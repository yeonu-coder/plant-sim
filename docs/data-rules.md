# 데이터 변환 규칙과 추천 점수 공식

이 문서는 `scripts/convert_nongsaro.py`와 `js/recommend.js`가 실제로 쓰는 규칙을 표로 정리한 것이에요.
코드의 규칙을 바꾸면 이 문서도 같이 바꿔야 해요.

## 1. 원본 데이터

| 항목 | 내용 |
|---|---|
| 출처 | 농촌진흥청 농사로 「실내정원용 식물」 Open API |
| 파일 | `data/plants_nongsaro.csv` (2024.07.16 수집, 인코딩 cp949, 227줄 × 141열) |
| 원칙 | 원본 CSV는 읽기만 하고 절대 고치지 않음 |
| 실행 | `python3 scripts/convert_nongsaro.py --check` (점검만) / `python3 scripts/convert_nongsaro.py` (점검 + 변환) |
| 다시 실행 | 같은 CSV면 몇 번을 돌려도 `plants.js` 결과가 같음 |

### 점검에서 발견한 원본의 특징

| 내용 | 이번 변환에 미치는 영향 |
|---|---|
| 이름만 있고 값이 빈 줄 10개 (로즈마리, 인도고무나무 등) | 로즈마리, 고무나무는 변환 못 함 → AI 초안 유지 |
| 이름이 겹치는 식물 2개 (렉스베고니아, 크로톤) | 우리 식물이 아니라 영향 없음 |
| `과_명` 열에 숫자 코드, `과_코드명` 열에 과 이름 (열 이름이 바뀐 것으로 보임) | 이 열은 안 씀 |
| 스킨답서스의 `관리수준코드명`이 빈 값 | 난이도만 AI 초안 값 유지 (`sourceNote`에 기록) |
| 파키라의 `독성정보`가 "해독작용" (독성 정보가 아님) | 반려동물 안전 여부는 원래 바꾸지 않음 |
| 행운목·테이블야자의 성장 높이가 200cm | 그대로 반영 → 크기 3(바닥) |
| 빈 값 표시가 섞여 있음 (`""`, `NA`, `N/A`) | 셋 다 빈 값으로 처리 |

## 3. CSV 문장 → 우리 조건값

### 빛 `light` — `광요구도코드명_1~3` 중 **가장 낮은 광도**

| CSV 값 | light |
|---|---|
| 낮은 광도(300~800 Lux) | 1 그늘 OK |
| 중간 광도(800~1,500 Lux) | 2 밝은 간접광 |
| 높은 광도(1,500~10,000 Lux) | 3 직사광 좋아함 |

예: "낮은 광도, 중간 광도, 높은 광도"가 모두 적혀 있으면 → 1 (낮은 빛에서도 자란다는 뜻)

### 물 주기 `waterDays` — `물공급봄·여름·가을코드명` 중 **가장 많이 나온 문장** (같으면 봄 기준)

| CSV 값 | waterDays |
|---|---|
| 항상 흙을 축축하게 유지함(물에 잠김) | 2 |
| 흙을 촉촉하게 유지함(물에 잠기지 않도록 주의) | 4 |
| 토양 표면이 말랐을때 충분히 관수함 | 7 |
| 화분 흙 대부분 말랐을때 충분히 관수함 | 14 |

⚠️ CSV에는 "며칠"이 없고 "흙이 어떤 상태일 때 주는지"만 있어요. 일수는 **우리가 정한 대략적인 기준**이에요.
겨울 물주기는 쓰지 않아요.

### 온도 `tempMin`, `tempMax` — `성장온도코드명`

| CSV 값 | tempMin | tempMax |
|---|---|---|
| 10~15℃ | 10 | 15 |
| 16~20℃ | 16 | 20 |
| 21~25℃ | 21 | 25 |

### 습도 `humidity` — `습도코드명`

| CSV 값 | humidity |
|---|---|
| 40% 미만 | 1 건조 |
| 40 ~ 70% | 2 보통 |
| 70% 이상 | 3 높음 |

### 난이도 `difficulty` — `관리수준코드명`

| CSV 값 | difficulty |
|---|---|
| 초보자 | 1 쉬움 |
| 경험자 | 2 보통 |
| 전문가 | 3 어려움 |

### 크기 `size`, `matureSize` — `성장높이정보`(cm), `성장넓이정보`(cm)

| 성장 높이 | size |
|---|---|
| 40cm 이하 | 1 작음(책상) |
| 41~100cm | 2 중간(선반·창가) |
| 100cm 초과 | 3 큼(바닥) |

`matureSize` 문구는 `"높이 약 {높이}cm · 폭 약 {넓이}cm"`로 만들어요.

### 바꾸지 않는 값과 예외

| 경우 | 처리 |
|---|---|
| 꽃말, 수명, 반려동물 안전, 이름, 소개, 가격, 이모지 | 변환하지 않음 (지금 값 유지) |
| CSV 값이 비어 있거나 표에 없는 문장 | 그 항목만 지금 값 유지, `sourceNote`에 기록 |
| 변환한 식물 | `source: "농사로 공공데이터"` |
| 출처가 "AI 초안"·"농사로 공공데이터"가 아닌 식물 (사용자가 직접 확인) | 스크립트가 건드리지 않음 |

## 4. 사용자 답변 → 숫자

| 질문 (`key`) | 선택지 → 값 |
|---|---|
| 경험 수준 (`level`) | 입문자 1 / 초보자 2 / 중급자 3 / 고수 4 |
| 물 챙기기 (`waterCare`) | 자주 챙김 1 / 가끔 잊음 2 / 거의 못 챙김 3 |
| 햇빛 (`light`) | 거의 안 듦 1 / 밝지만 직접 안 듦 2 / 쨍하게 듦 3 |
| 온도 (`temp`) | 서늘 15 / 적당 21 / 따뜻 27 (℃) |
| 습도 (`humidity`) | 건조 1 / 보통 2 / 촉촉 3 |
| 외출 (`away`) | 거의 집에 있음 1 / 가끔 비움 2 / 잦음 3 |
| 반려동물 (`pet`) | 있음 true / 없음 false |
| 공간 (`space`) | 책상 1 / 선반·창가 2 / 바닥 3 |

### 물 없이 버텨야 하는 일수 `D`

`D = max(CARE_DAYS[waterCare], AWAY_DAYS[away])`

| 값 | 1 | 2 | 3 |
|---|---|---|---|
| CARE_DAYS (물 챙기기) | 3일 | 7일 | 14일 |
| AWAY_DAYS (외출) | 3일 | 5일 | 10일 |

## 5. 추천 점수 공식 (`js/recommend.js`)

식물마다 아래 점수를 **모두 더해요** (만점 약 100점). 항목 점수는 0 아래로 내려갈 수도 있어요(빛·습도·공간·난이도).

| 항목 | 만점 | 계산 |
|---|---|---|
| 빛 | 25 | `차이 = 식물 light − 사용자 light`<br>차이 > 0 (빛 부족): `25 − 15 × 차이`<br>차이 ≤ 0 (빛 넉넉): `25 − 6 × |차이|` |
| 물 | 20 | `waterDays ≥ D`면 20<br>아니면 `max(0, 20 − 2 × (D − waterDays))` |
| 온도 | 15 | 사용자 온도가 `tempMin~tempMax` 안이면 15<br>밖이면 `max(0, 15 − 3 × 벗어난 ℃)` |
| 습도 | 15 | `차이 = 식물 humidity − 사용자 humidity`<br>차이 > 0: `15 − 8 × 차이`<br>차이 ≤ 0: `15 − 4 × |차이|` |
| 공간 | 10 | `차이 = 식물 size − 사용자 space`<br>차이 > 0 (자리보다 큼): `10 − 8 × 차이`<br>차이 ≤ 0: `10 − 3 × |차이|` |
| 난이도 | 15 | `넘침 = difficulty − 편한 난이도[level]`<br>넘침 > 0: `15 − 넘침 × 감점[level]`<br>넘침 ≤ 0: 15<br>고수(4)는 추가로 `+ (difficulty − 1) × 4` |
| 반려동물 | — | 반려동물 있음: `petSafe: false`는 **추천에서 제외**, `null`은 `−30` |

### 경험 수준별 난이도 기준

| level | 편한 난이도 | 넘을 때 한 단계당 감점 | 추가 |
|---|---|---|---|
| 1 입문자 | 1 | 20 | |
| 2 초보자 | 1 | 10 | |
| 3 중급자 | 2 | 8 | |
| 4 고수 | 3 | 0 | 어려울수록 가산점 |

### 순위 정하기

1. 점수 높은 순
2. 같으면 난이도 낮은 순
3. 그래도 같으면 이름 가나다순

위에서 3개를 골라요.

### 추천 이유 한 줄

각 카드에서 아래 후보 중 **조건에 맞는 첫 번째 이유**를 보여줘요. 앞 카드에서 이미 쓴 이유는 건너뛰고, 맞는 게 없으면 "우리 집 환경과 두루 잘 맞아요"를 보여줘요.

| 순서 | 조건 | 이유 |
|---|---|---|
| 1 | 햇빛 1 & 식물 light 1 | 그늘에서도 잘 자라요 |
| 2 | 햇빛 2 & 식물 light 2 | 밝은 간접광이 드는 방에 딱 맞아요 |
| 3 | 햇빛 3 & 식물 light 3 | 햇빛이 잘 드는 방을 좋아해요 |
| 4 | D ≥ 7 & waterDays ≥ 14 | 물을 자주 안 줘도 돼요 |
| 5 | D ≤ 3 & waterDays ≤ 5 | 자주 물을 챙겨주면 더 잘 자라요 |
| 6 | 습도 1 & 식물 humidity 1 | 건조한 방에서도 잘 버텨요 |
| 7 | 습도 3 & 식물 humidity 3 | 촉촉한 공기를 좋아해요 |
| 8 | 온도 ≤ 15 & tempMin ≤ 15 | 서늘한 방에서도 잘 지내요 |
| 9 | 온도 ≥ 27 & tempMax ≥ 27 | 따뜻한 방에서도 잘 지내요 |
| 10 | 공간 1 & size 1 | 책상 위 작은 자리에 쏙 들어가요 |
| 11 | 공간 2 & size 2 | 선반이나 창가에 두기 좋은 크기예요 |
| 12 | 공간 3 & size 3 | 넓은 자리를 시원하게 채워줘요 |
| 13 | waterDays ≥ D | 물 주기가 생활패턴과 잘 맞아요 |
| 14 | level ≤ 2 & difficulty 1 | 처음 키워도 어렵지 않아요 |
| 15 | level 3 & difficulty ≥ 2 | 조금 손이 가지만 키우는 재미가 있어요 |
| 16 | level 4 & difficulty 3 | 고수의 손길에 보답하는 까다로운 식물이에요 |
| 17 | 반려동물 있음 & petSafe true | 반려동물과 함께 지내도 안전해요 |
